# شهرک‌ساز | Unity 3D Tycoon

یک نمونه اولیه سه‌بعدی موبایل با Unity 2022.3 LTS و C#.

## اجرا
1. Unity Hub را باز کنید.
2. گزینه **Add project from disk** را بزنید و پوشه `UnityTycoon` را انتخاب کنید.
3. پس از باز شدن پروژه، صحنه `Assets/Scenes/Tycoon.unity` به‌صورت خودکار ساخته می‌شود.
4. دکمه Play را بزنید.

## گیم‌پلی
- شروع با ۵۰۰ سکه
- خرید و ساخت فروشگاه و کارخانه روی زمین‌های خالی
- درآمد خودکار در هر ثانیه
- انتخاب ساختمان و ارتقای آن
- دوربین ایزومتریک با کشیدن انگشت و زوم لمسی
- رابط فارسی و مناسب صفحه موبایل

## خروجی اندروید
از مسیر **File > Build Settings > Android > Switch Platform** پلتفرم را عوض کنید، سپس **Build** را بزنید. برای خروجی APK باید Android Build Support در Unity Hub نصب باشد.

این نسخه یک نمونه اولیه قابل توسعه است؛ برای انتشار نهایی باید آیکون، صدا، ذخیره‌سازی دائمی و تنظیمات نهایی اندروید اضافه شوند.
