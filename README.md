# پادشاهی کوچک — Little Kingdom

بازی استراتژی و قلعه‌سازی سه‌بعدی برای Android با Godot 4.3.

## امکانات نسخه اولیه
- محیط سه‌بعدی کارتونی با قلعه، درخت، مسیر و زمین
- صفحه افقی موبایل
- ساخت مزرعه، برج دفاعی، سربازخانه و دیوار
- منابع سکه و چوب و درآمد دوره‌ای مزرعه
- موج دشمن، دفاع خودکار و ارتقای سلامت قلعه
- کنترل لمسی و رابط فارسی

## ساخت APK
Workflow در GitHub Actions با هر Push روی شاخه main اجرا می‌شود. فایل APK در بخش Actions به‌عنوان Artifact منتشر می‌شود.
