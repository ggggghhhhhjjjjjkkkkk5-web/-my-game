# قلعه‌بان — Castle Defender

بازی دفاع از قلعه برای Android، ساخته‌شده با Godot 4.3.

## بازی
- دفاع از قلعه با سه سرباز اولیه و تیراندازی خودکار
- دشمنان موجی با افزایش تدریجی سرعت
- تیراندازی دستی، استخدام سرباز، تعمیر و تقویت دفاع
- کنترل لمسی و رابط فارسی
- خروجی Android با معماری ARM64

## ساخت APK
فایل workflow در GitHub Actions با هر Push اجرا می‌شود و APK را به‌عنوان Artifact با نام `Castle-Defender-Android-APK` منتشر می‌کند.
